# 本地隔离测试环境

## 启动

在仓库先执行 `cd frontend && VITE_API_BASE_URL='' npm run build`，回到仓库执行 `npm run lab:isolated`。
访问 http://127.0.0.1:4174/，页面顶部应出现红色“隔离测试环境”标识。
端口被占用时启动失败，不会关闭已有服务。

## 隔离范围

- 每次启动创建新的临时目录，并输出 `ISOLATED_LAB_ROOT`；代码、数据、附件和日志落在副本中。
- 不复制现用客户数据库、附件、`.env` 或浏览器登录资料。只共享已安装的 node_modules。
- 使用本地测试管理员、独立 JSON 存储、同源前后端，只监听本机 127.0.0.1。
- 瑞云、飞书连接器替换为拒绝访问的实现；所有瑞云写入开关关闭，恢复后台任务关闭。
- 这是应用层连接器隔离，不是操作系统网络沙箱。不要在此环境输入真实客户资料或凭据。
- 不连接现用瑞云浏览器。独立地址隔离网页站点状态，但尚未建立真实瑞云测试浏览器或测试账号。

## 检查

- `/api/health` 应显示 dryRun 为 true，所有写入开关为 false。
- `/api/lab-status` 显示副本路径、syntheticOnly 为 true。
- `/api/auth/me` 应返回 LOCAL-ADMIN。
- `node --test test/isolated-lab.test.js` 检查文件筛选规则。

外部工单查询会失败，这是本环境有意禁止外部连接的结果，并不代表查询业务验收通过。
下一步需加入模拟工单和故障注入，验证重启恢复、重复提交、并发和附件处理；真实瑞云读写须另行安排授权测试。

## 停止和保存

在启动本环境的终端按 Ctrl+C，仅停止本测试进程。不要停止现用 FieldDesk 服务。
每次启动是新的空白副本；临时目录可能被系统清理，不用于正式业务或长期保存。
此入口不能从手机访问，也不是服务器部署。
