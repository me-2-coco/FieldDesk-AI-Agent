# 瑞云业务节点同步字段清单

当前同步层仅启用 `DRY_RUN` 适配器。真实适配器不会打开瑞云、查询页面或执行写入。

| 节点 | 已完成的本地字段映射 | 启用真实同步前仍需确认 |
| --- | --- | --- |
| 签收 | 寄修单号、物流单号、SN、维修品类、签收备注、签收时间 | 签收表单字段名、产品行唯一键、最终确认动作及成功状态 |
| 检测完成 | 检测结果、检测备注、检测完成时间 | 瑞云检测节点入口、固定结果枚举、附件要求及提交成功状态 |
| 维修完成 | 三级故障、责任/质保类型、维修措施、实际使用配件、附件数量、完成时间 | 三级故障代码、责任枚举代码、配件明细字段、附件上传协议及完工成功状态 |
| 返件发货 | 物流公司、返件物流单号、发货时间、凭证数量 | 物流公司代码、物流单字段、凭证上传协议及发货成功状态 |
| 工单完结 | 本地完结时间 | 瑞云服务完结入口、必填结论字段及最终状态 |

真实适配器启用前还需统一确认：各节点 API 或页面入口、幂等查询方式、权限错误、登录失效、限流、超时、页面结构变化和成功回执的判定规则。
