# 人工审核试运行

服务端 `RECLOUD_MANUAL_REVIEW_REQUIRED=true`。缺省、拼写错误均禁止自动最终提交；只有负责人明确决定恢复自动模式后才设置为 `false`，不得通过工单请求参数覆盖。

系统继续签收、检测、维修资料、配件与附件核对、点击完工及返厂旧件标签入队，停在维修单最终“提交”前。上述动作仍会写入瑞云，不是只读预览。

信息员通过异常中心的待提交记录核对瑞云，并在瑞云手动提交。待审核断点再次运行时只读查询最终状态，不重复配件、附件、标签或完工。后台巡检间隔至少五分钟；最终状态确认后清除待审核提醒。未知结果不等于未提交。

已进入待审核的工单不会因将来开启自动模式而自动提交；其断点仍按只读核对处理。已正式提交的历史工单不撤回。

此开关仅定义维修单最终提交边界，不代表发货、送修等未验收分支获准上线。部署前仍须验证 HTTPS、账号权限、备份恢复、打印终端及真实瑞云人工审核闭环。
