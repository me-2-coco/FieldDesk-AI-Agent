# FieldDesk 部署前人工验收清单

验收环境必须保持 `DRY_RUN=true`、`RECLOUD_WRITE_ENABLED=false`、`RECLOUD_REVEAL_PHONE_ENABLED=false`，仅使用本地测试工单和模拟库存。

## 账号管理

- 扫地机师傅 `zhang`：可处理扫地机工单、查看个人库存；洗地机工单应被后端拒绝。
- 洗地机师傅 `li`：可处理洗地机工单、查看个人库存；扫地机工单应被后端拒绝。
- 双品类师傅 `zhao`：查询产品线不明确时必须选择本单品类。
- 库房 `wang`：只能进入库存、退还确认、返件发货；不能进入维修执行页面。
- 管理员 `admin`：可进入全部本地流程、账号管理、同步管理，并确认工单完结。

## 完整业务路径

1. **到店查询**：主页点击“到店查询与签收准备”，输入测试物流单号。预期展示寄修单、用户、故障和产品线；此步骤以 mock/只读数据验收，不操作瑞云。
2. **签收准备**：点击“下一步：录入 SN”，扫码或手输 SN。预期自动大写，备注按账号品类生成；保存后显示“尚未同步瑞云”。点击“完成本地签收并进入检测”。
3. **检测登记**：预期自动进入检测页并显示工单号、物流单号、SN、产品线、报修描述。填写检测结果并保存，状态变为“检测完成/待维修”，出现“申请配件”和“进入维修完工”。
4. **配件申请与使用**：申请有库存的配件，预期总库扣减、个人库存增加，状态进入等待配件；进入个人库存使用配件后可返回维修完工。库存为零、超量申请或使用必须失败。
5. **维修完工**：选择三级故障和责任类型，确认维修措施包含固定话术与实际使用配件；可保存草稿。提交后状态为“维修完成/待发货”，出现返件发货入口。
6. **返件发货**：选择物流公司，扫码或输入返件单号，可上传照片。提交后状态为“已发货/待完结”；重复提交或空物流号必须失败。
7. **管理员完结**：切换管理员，在返件发货页选择待完结工单并点击“管理员确认完结”。预期状态为“已完结”，再次完结失败，并产生本地 outbox 任务但不写瑞云。

## 续办与异常

- 每个节点返回主页后，“继续当前工单”应按状态进入检测、配件/库存、维修完工或返件发货页面。
- 页面空字段统一显示“-”或“未提供”，不得显示 `undefined`。
- API 失败时页面应显示可读错误，不改变当前本地状态。
- 全流程不得出现瑞云最终确认行为；五节点同步任务仅进入 outbox。
